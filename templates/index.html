This is a simulator that allows you to compare the speeds of basic arithmatic (like addition, subtraction, multiplication, and division) using different arithmatic methods. This is done by counting the number of steps it takes for calculations which allows us to isolate the amount of time it takes for each type of calculation, allowing us to optimize arithmatic to create a new generation of little human calculators. By finding the optimal way to do math we can improve the process of doing arithmatic for every single person.
To use the simulator input the first number on the left, select the operation on the dropdown menu in the center and the input the second number on the right. You must put the larger number on the left for division and subtraction or it will not work. Also no negative numbers or decimals, thats too complicated.
